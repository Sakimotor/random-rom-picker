Hi everyone, I would like to suggest something cool today, how about we open a **VGMQ Gaming Club** ?

The concept is pretty simple: Every week (or month, depending on whether the current game is a short one like a Beat'em Up/SHMUP or something more full-fledged like an RPG), I'll *randomly* pick 5 games from a premade list (more details below). Then, all 5 games would have a track assigned in a custom room, and the first track to play would define the game of the week/month, ensuring actual randomness. Preferrably, the reveal about which game is chosen would be made with the other club members who'd join the custom and see the result in real time with me! 

The list would consist of games belonging to the 3rd-7th gens (so the NES-Gamecube eras) so everyone could at least emulate the chosen titles. Windows PCs will for now be excluded as I have no way of sorting out which game is recent and which isn't (TODO: using myabandonware.com's game list ?). English and Japanese games are included, Japanese-only games will be skipped if understanding the text is vital to the progress.

There wouldn't be any real objective beyond simply having fun and exchanging about a specific game, helping each other whenever needed. We'd make one thread per game, so our past play history could easily be tracked and reacted upon if needed. Most importantly, every participant's play session would be **asynchronous**, meaning it wouldn't matter whether you play the whole week, or for a day, in the night, or during daytime, as long as you're trying the games out and having your fun. You can see it as a no-pressure version of [AOTW](https://retroachievements.org/forums/topic/29289). 

Every new game choice would occur on a Monday evening (CEST) so everyone could have the time to play through the week. 

The first game will be chosen this Monday, see you then!
